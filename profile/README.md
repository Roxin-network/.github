# Roxin

Roxin is building infrastructure for transferring value between video games.

The **ROXIN token** is designed to act as the value-transfer layer of the ecosystem, allowing value earned or held in one game to move into another participating game.

## ROXIN Token

- **Symbol:** ROXIN
- **Network:** BNB Smart Chain
- **Utility:** Cross-game value transfer and ecosystem governance
- **Total Supply:** 200,000,000,000 ROXIN

Roxin is currently in its pre-seed stage. Token allocation, vesting, governance, and ecosystem design are documented in the litepaper.
